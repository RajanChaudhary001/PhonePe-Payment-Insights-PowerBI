# 📱 PhonePe Payment Insights – Power BI Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard designed to analyze
PhonePe payment transaction data and generate meaningful business insights.

The dashboard provides an overview of transaction performance, payment
value, users, success rate, service usage, and user activity patterns.

## 🎯 Key KPIs

- Total Transactions: 25K
- Total Transaction Value: 452.83M
- Unique Users: 7.639K
- Success Rate: 100%

## 📈 Dashboard Features

- Transactions Over Time
- Age Segment Contribution
- Service Transaction Value Analysis
- Top 5 Users
- Weekday vs Weekend Usage
- Monthly Transaction Analysis
- Payment Status Filter
- Interactive Month Filter

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel / CSV
- Data Visualization

## 💡 Key Insights

- Monthly transaction trends can be analyzed using the time-series chart.
- User contribution can be compared across different segments.
- Service categories can be evaluated based on transaction value.
- Top users can be identified using transaction activity.
- Weekday and weekend usage patterns can be compared.
- Payment status and month filters allow interactive analysis.
